Where the drawing disagrees with the stated hypotheses
------------------------------------------------------------------------
- J107 rails: confirmed in part. J107-7 = "24V", J107-3 = "15V" (shown as
  "15V", no "+" sign), J107-4 = "-15V". J107-2 is also labelled 24V, but it
  is the K103 relay coil / D114 cathode feed, not a second plain rail tap.
  J107-1 is not a ground return on the card: it is the Q120 emitter (relay
  driver), with no dot to the bus. It could be a function-select / switched
  return. J107-5 and J107-6 have no card wire.
- J104: the drawing does NOT show any of J104-1..7 reaching the Q110 (INPUT) /
  Q106 (SYNC) / Q105 (REPRO) gate diodes D112 / D107 / D106 within the segments
  traced. J104-1 goes through D119 to the Q107 gate (a JFET with no
  INPUT/SYNC/REPRO label, near the input stage; possibly a mute switch, but
  that is not printed). The other J104 lines go into the Q108/Q109 stage:
  J104-2 Q109 emitter (24V); J104-4 D118 -> R204 -> Q109 collector line;
  J104-3 D109 -> R139 -> Q108 base network; J104-5 24V -> R135 -> D108;
  J104-6 Q108 emitter. No J104 contact shows a ground or return label.
  J104-7 has no card wire. The OUT SELECT lines for Q110/Q106/Q105 must arrive
  on some other connector (they run down x~6412, 6455, 6599 toward the
  -15V/R126/R131/R125 area; I did not trace them).
