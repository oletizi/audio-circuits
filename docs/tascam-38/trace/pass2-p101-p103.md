Pass 2 (motherboard side): P101 pins 1-4, P103 pins 1-6
=========================================================

Source: scratchpad/amp/full-1.png (9000 x 5250, 300 dpi). All coordinates are
full-res pixels (x, y). Crops are in scratchpad/agent2-p101-p103/.

Method: each run was followed visually in 3-10x crops. Small helper scripts in
the crop folder (vtrack.py, hwalk.py, tileall.py) listed every crossing along
each run, and every crossing was then looked at in tiled 3x crops (tA-*, tB-*,
tC-*, tD-*.png). The scripts' automatic dot score turned out to be unreliable:
it missed the dot at (6733,2963) and scored some plain crossings high. So every
junction call below comes from looking at the crops, not from the score.

Drawing-wide observations that affect every run
-----------------------------------------------
- At x ~4398, x ~2305 and x ~6477, every horizontal bus has the same 1-4 px
  break where a faint dashed vertical crosses it. This looks like a seam or
  paste-up edge in the drawing, not a wire break, and I treated those buses as
  continuous. It shows on every bus at the same x, so it is not specific to
  any one net. Crop: z4400.png (4200 2700 4450 2870).
- At x ~4762, all buses step 2 px vertically. This is a scan-stitch offset
  and the lines are continuous. Crop: z4745.png (4700 2740 4800 2850).
- Every channel-1 P10x vertical that goes down carries on straight to the
  same-numbered pin of the 2ch-8ch REC/PLAY AMPL row (P101/P103 prongs pointing
  down at y ~3790-3810, J101/J103 boxes at y ~3825-3875). Crop: col3.png
  (4780 3440 5200 3880).
