# P107-1 to P104-6 motherboard trace

Source: high-resolution amplifier schematic p2(1).pdf, right-hand motherboard connector area.

A horizontal conductor with junction dots connects motherboard P107 pin 1 to P104 pin 6. This directly supports the owner's separate return/ground annotations for J107-1 and J104-6, but the visible connection establishes electrical continuity only; its noise/current return role remains to be characterized.

This is a **motherboard-side connection**. The matching card contacts are J107-1 and J104-6; their card-side wiring is a separate tracing task.

Do not conflate this with the adjacent power and switching buses crossing the same region.
