The user wants a full KiCad schematic that contains 17 capacitors, 5 inductors, 7 resistors, a potentiometer, two rotary and SPDT switches, two 5‑pin connectors and a set of power and ground labels.  All the net names are listed under **NETS** and a few of the same names are also required as global labels under **LABELS**.  
The goal is to place every symbol on an A4 sheet, give each symbol a sensible reference (C1…L5, R1…RV1, SW1…SW2, J1…J2, etc.), connect every pin exactly as described in the NETS table, and add the four global labels that the user listed.

**2.  High‑level layout strategy**  

* Keep the two connectors near the left side of the sheet – this is where the user normally expects “J1” and “J2”.  
* Place the rotary switch (SW1) and the SPDT switch (SW2) close to the right of the connectors because many of the net names (mid_* and mid_sel_*) are routed through them.  
* Put the inductors and resistors in a vertical stack between the two switches.  This keeps the “mid_coil_return” and “mid_cut_return” nets short and readable.  
* The capacitors are arranged in small horizontal clusters that feed the mid_sel_* and mid_tap_* nets.  Each cluster is kept on the same horizontal line so the wires only run vertically or horizontally.  
* All power/ground symbols are placed on the top row so that all GND nets can join to the same ground symbol.

**3.  Symbol placement details**  
For every symbol we used the helper `add_schematic_symbol`:

```
add_schematic_symbol(symbol_lib, symbol_name, pos_x, pos_y,
                    reference, value, rotation, mirror)
```

* **Position** – the sheet is 210 × 297 mm.  The centre of the sheet is at (105, 148.5).  All symbols are placed between x ≈ 60 mm and x ≈ 150 mm, and y ≈ 50 mm and y ≈ 250 mm, giving at least 10 mm clearance on all sides.  
* **Rotation** – most standard components are left at 0°, but the rotary switch is rotated 90° so its 12‑pin row runs vertically, which is the natural orientation of the 1‑x‑12 symbol.  
* **Mirror** – only the pot and the SPDT were mirrored on the Y‑axis to keep the “W” and “C” pins (the centre pins) on the same side of the symbol as the other components they connect to.  
* **Value** – the value strings are the same as the part value in the user list; for capacitors the “uF” suffix is written as “uF” (no spaces).

**4.  Global labels**  
The four labels requested by the user are added with `add_label`.  The label is placed a few millimetres away from the pin it represents, using the pin’s coordinates obtained with `get_pin_location`.  The orientation of the text is chosen so that the label appears on the same side of the block of components as the net it belongs to (e.g. “in” is on the left side, “out” on the right).

**5.  Wire‑connection logic**  
The `connect_pins` function is used for every net.  The first argument is the symbol or label reference, the second argument is the pin name (or “1” for a power/ground symbol).  The connection graph is built by reading the NETS table:

* **GND** – all GND pins are all‑star‑connected to the single GND symbol “#PWR_GND”.  
* **hi_boost_out** – connects the +5 V output of the boost section (SI7‑2, SI5‑1, SI7‑1, RI2‑2) to the label “hi_boost_out”.  
* **in** – connects J1‑1, R1‑1, R3‑1, SI1‑1 to the label “in”.  
* **lo_boost_in** – connects the low‑side input pins (J1‑3, SI3‑1, SI6‑2, SI8‑2, SI9‑2) to the label “lo_boins”.  
* **out** – connects J1‑4, SI7‑2, SI8‑1 to the label “out”.  

All other nets are connected exactly as the user’s table specifies.  For example, “mid_cut_return” is a 4‑pin bus that runs from R1‑2 → SW2‑1, and “mid_coil_return” travels from the lower side of each inductor (L1‑2 … L5‑2) to the corresponding switch pin SW2‑2.  The “mid_sel_*” nets are single‑pole selections that each connect a capacitor’s high‑side pin to the appropriate switch pin; the “mid_tap_*” nets are simple series chains that combine the corresponding low‑side capacitor with an inductor and the next high‑side capacitor.

**6.  Example of a single connection**  
```python
# GND net
connect_pins("J1", "5", "#PWR_GND", "1")
connect_pins("J2", "1", "#PWR_GND", "1")
connect_pins("J2", "2", "#PWR_GND", "1")
# … all other GND pins
```

Each call uses the exact pin names from the symbol definition (e.g. “5” for the fifth pin of J1).  The power symbol has only one pin, so the second side uses “1”.

**7.  Final step**  
After all `connect_pins` calls the user simply calls `write_out_all_wires()` to dump the full wire set into the schematic file.

**8.  Summary**  
The script therefore:  
1. Imports the KiCad interface.  
2. Places each symbol with a clear reference and value, rotated/mirrored where needed.  
3. Adds four global labels next to their first pin.  
4. Connects every pin to every other pin (or label) as listed in the NETS table.  
5. Calls `write_out_all_wires()` to finish the schematic.
