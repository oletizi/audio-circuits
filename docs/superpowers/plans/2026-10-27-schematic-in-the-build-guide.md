**Goal:** `boards/pultec-low-cut/guide/guide.pdf` and `boards/pultec-low-boost/guide/guide.pdf` each carry a schematic page the owner has looked at and accepted.

## Global Constraints

- **No invented readability score.** Only closed-form properties may be measured: crossings, corners, fallback field placements, content inside the page, a junction at every branch. Whether a drawing *reads* has no closed form and no proxy for it may be built. The owner's word "turbulence" is a judgement, not a metric.
- **The agent never authors the criteria for the artifact it produces.** Acceptance is the owner looking at the rendered page.
- **Every iteration goes to the owner**, not only the one offered for acceptance, and each one carries the agent's own assessment of what it sees. An iteration sent without an assessment is a step skipped.
- **One change per iteration.** Two changes between two lookings attribute nothing.
- **`docs/known-gaps.md` is FROZEN.** Do not add to it. The single exception is an owner decision or declination in his own words. A measurement goes in a tool or a test that re-runs it; a defect not being fixed goes in a comment beside the code or in the refusal message; an undiagnosed observation goes in this plan or the spec.
- **Commit only paths you changed.** Never `git add -A` — another session shares this worktree.
- **Compare `Ran` across runs.** `pass + fail == Ran` does not catch a throwing `beforeAll`, which has masked tests three times here. The baseline is **`Ran 3872`** at `537a076`.

```ts
/**
 * **CLOSED-FORM GEOMETRY OF A DRAWING'S WIRES. It is not a readability score and may not become
 * one.** `CLAUDE.md` and the constitution's first principle forbid inventing a number that stands
 * in for a person's judgement of whether a drawing reads; three such proxies were invented in two
 * days and each pointed the opposite way to the owner's judgement on a specific occasion.
 *
 * **What these two ARE:** a crossing is two segments of DIFFERENT nets meeting at a point interior
 * to both, which is a thing a reader's eye must resolve and KiCad draws no junction for. A corner
 * is a vertex where one net's path changes axis. Both have closed forms. Neither is combined with
 * the other, weighted, or thresholded here - a caller that does so is building the forbidden thing.
 *
 * **Same-net crossings are deliberately NOT counted.** Two segments of one net meeting is that
 * net's own geometry and carries a junction; counting it would make a correct star topology look
 * like clutter.
 */
import type { Wire } from "./block-types.ts";

export interface WireGeometry {
  /** Different-net segment pairs meeting interior to both. */
  readonly crossings: number;
  /** Vertices where one net's path changes axis. */
  readonly corners: number;
  /** Segments measured, so a zero is distinguishable from an empty block. */
  readonly segments: number;
}

const horizontal = (w: Wire): boolean => w.a.y === w.b.y;
const vertical = (w: Wire): boolean => w.a.x === w.b.x;

/** Strictly between, so a touch at an endpoint is a corner rather than a crossing. */
const between = (v: number, lo: number, hi: number): boolean =>
  v > Math.min(lo, hi) && v < Math.max(lo, hi);

function crosses(p: Wire, q: Wire): boolean {
  if (p.net === q.net) return false;
  const [h, v] = horizontal(p) && vertical(q) ? [p, q] : vertical(p) && horizontal(q) ? [q, p] : [];
  if (h === undefined || v === undefined) return false;
  return between(v.a.x, h.a.x, h.b.x) && between(h.a.y, v.a.y, v.b.y);
}

export function wireGeometry(wires: readonly Wire[]): WireGeometry {
  let crossings = 0;
  for (let i = 0; i < wires.length; i++) {
    for (let j = i + 1; j < wires.length; j++) {
      const p = wires[i];
      const q = wires[j];
      if (p !== undefined && q !== undefined && crosses(p, q)) crossings++;
    }
  }

  let corners = 0;
  for (let i = 0; i < wires.length; i++) {
    for (let j = i + 1; j < wires.length; j++) {
      const p = wires[i];
      const q = wires[j];
      if (p === undefined || q === undefined || p.net !== q.net) continue;
      if (horizontal(p) === horizontal(q)) continue;
      const ends = [p.a, p.b];
      const theirs = [q.a, q.b];
      if (ends.some((e) => theirs.some((t) => t.x === e.x && t.y === e.y))) corners++;
    }
  }

  return { crossings, corners, segments: wires.length };
}
```

The core:

```ts
const rows: string[] = []
for (const ref of boardRefs(repoRoot)) {
  const declared = ALL_DECLARED_CASES.find((c) => c.entry === `${ref.export}()`)
  if (declared === undefined) {
    rows.push(`${ref.name}: no-declaration (${ref.export})`)
    continue
  }
  try {
    const g = await generate(parityDesign(declared, caseResolver([declared]), repoRoot, outDir), env)
    // ONE ROW PER BLOCK would be the wrong unit here: the owner's test is the BOARD, and a
    // per-block table lets five clean blocks hide one unreadable one. Folded per board, with the
    // segment count kept so a zero is distinguishable from a board that drew nothing.
    const geo = g.drawings.map((d) => wireGeometry(d.wires))
    const sum = (pick: (x: WireGeometry) => number): number => geo.reduce((n, x) => n + pick(x), 0)
    const fallbacks = g.drawings.reduce((n, d) => n + d.fieldFallbacks.length, 0)
    rows.push(
      `${ref.name}: segments ${sum((x) => x.segments)}, crossings ${sum((x) => x.crossings)}, ` +
        `corners ${sum((x) => x.corners)}, fallbacks ${fallbacks}`,
    )
  } catch (e) {
    // THE REFUSAL IS PRINTED IN PLACE OF THE NUMBERS, never beside zeros. A row of zeros for a
    // board that drew nothing reads as a clean drawing, which is the failure the whole workflow
    // exists to prevent (CLAUDE.md: a skipped check must never look like a passing one).
    rows.push(`${ref.name}: REFUSED - ${e instanceof Error ? e.message : String(e)}`)
  }
}
console.log(rows.join("\n"))
```

**`withheld` is a FOURTH variant and not a reuse of `none`, and this matters.** The spec says a failing sheet "degrades to the existing no-schematic notice". **Deviate from that mechanism and keep its criterion.** `none` means *this board declares no schematic*; `withheld` means *a schematic was generated and judged unfit to build from*. Those are two different claims about two different situations, and `guide.ts`'s own comment says the union exists so that an absence is "a shape this file has to handle rather than a field it can skip". Printing one claim for both is the failure that comment names. The criterion the spec actually sets — a wonky sheet must not reach the bench — is met either way.

**The gate:** `drawings.every((d) => d.fieldFallbacks.length === 0)`. A fallback placement *is* text drawn over something; that is what the type means.
