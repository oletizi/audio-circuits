# Drawing the staged preamp with copperhead

**Status:** proposed, awaiting the owner's review. Nothing below is built yet.

## Why

The owner asked whether the copperhead-and-akcli drawing procedure
(`TOOLING.md`, invoked through `.claude/skills/drawing-a-schematic/SKILL.md`)
can produce a schematic drawing of `transistor-preamp-staged`.

The board already has a sheet, `circuits/transistor-preamp/staged-board.kicad_sch`:
the old generator's stub, rearranged by the owner in `fd582f9`, with a
`PWR_FLAG` added in `f3dca40` so it passes ERC. That sheet is the one
`perfboard.json` names and the one page 2 of the build guide prints. **This
work does not touch it.** The copperhead page is a second, separate candidate.

## Which way authority runs

`transistor-preamp-staged` is an agent-designed circuit, so **the model is
authoritative** and the drawing is derived from it (`TOOLING.md` step 0). The
authority for the circuit is `staged-board.ts`, whose own authority is
`docs/superpowers/specs/2026-09-28-transistor-preamp-staged-design.md`.

## What gets built

### 1. An intent derived from the model, by code

`make draw` drafts only for a board with an entry in `COMMITTED_INTENT`
(`tools/draught/draw-draft.ts`). **Every Pultec page started from a copperhead
intent**, and those intents are committed in the boards' research run
directories (`docs/research/2026-10-29-{hi-cut,hi-boost,low-cut,mid}-full-run/`,
and `2026-10-29-copperhead-against-the-idiom/inputs/` for low-boost). They are
hand-written JSON, with grouping variants generated by each run's own scripts.
**Only `pultec-hi-cut`'s is registered in `COMMITTED_INTENT`**; the module's
own comment says the other four have no entry yet. Registering them is outside
this spec.

The Pultec is schematic-authoritative, so its intents were transcribed from a
netlist. The staged preamp is model-authoritative, which is the reason this
spec departs from the five hand-written precedents.

For this board the intent is **generated from the `Network`**, not typed by
hand. Every fact the intent needs is already in the model:

| intent field | comes from |
| --- | --- |
| `parts[].ref` | `DESIGNATORS` in `staged-board.ts` |
| `parts[].libId` | each component's `symbol` (`circuits/transistor-preamp/parts.ts`) |
| `parts[].value` | each component's value |
| `nets[].pins` as `REF.PIN` | net membership in the `Network`, pin numbers through `symbolPins` / `PIN_NUMBERS` |
| `nets[].kind` | `ground` for `GND`; `power` for `VCC` |
| `parts[].group`, `hints.groupOrder` | **a committed group map - the one judgement input** |

A small module, `tools/draught/intent-from-network.ts`, does the derivation.
It refuses by name on any component with no designator, no `symbol`, or no
group, rather than defaulting one. It is tested over the five
transistor-preamp boards' models, not only this one.

`make draw` then verifies the generated intent against the board's committed
netlist export (`tests/fixtures/transistor-preamp-staged.net`), as sets of
`REF.PIN` sets, which it already does for hi-cut. **A disagreement stops the
draft before a coordinate is placed** - the one refusal `EVALUATING-DRAWINGS.md`
§3 allows.

### 2. One group

Group assignment is the main lever copperhead gives (`TOOLING.md` step 2).
**Every part goes in a single group**, the owner's call: the Pultec pages are
divided into sections because that circuit is a set of separate bands joined
at a junction, and the staged preamp is one signal chain.

What that buys and costs is measured, in
`docs/research/2026-10-29-copperhead-against-the-idiom.md` §3 and §5, on the
low-boost circuit:

- copperhead draws a net as wire only when all its endpoints are in one group,
  so one group lets the signal chain be wired rather than labelled. Single-group
  drafts there measured a longest continuous run of 88.9-161.3 mm, against
  74.9 mm or less for every multi-group draft;
- one group is one box with one caption, so the stages are not titled;
- a net with more than four endpoints (`MAX_WIRED_ENDPOINTS`) still becomes
  labels in any grouping, so `VCC` and `GND` will be labels or power symbols;
- `hints.groupOrder` is inert with one group.

The group's caption is the only free text copperhead places. It is
`Transistor preamp - staged`, held in the drawing file below.

The procedure says to draft more than one arrangement. With one group the
remaining inputs are minor ones the same research measured (`parts[]`
declaration order, net `kind` on ground), so the first draft is taken through
the loop and further variants are drafted only if the first leaves something
those inputs could change.

### 3. Where things live

| what | where | why |
| --- | --- | --- |
| drawing inputs: the group and its caption (edited here) | `circuits/transistor-preamp/staged-board.drawing.ts` | a source beside its circuit (`CLAUDE.md`: ask whether it will be edited here) |
| derivation module | `tools/draught/intent-from-network.ts` | tooling, with the other draught modules |
| draft, repairs, renders | `drafted/transistor-preamp/transistor-preamp-staged/` | the same shape as `drafted/pultec/`, with a `RECORD.md` |

### 4. The loop, run as the procedure says

`make draught-doctor`, `make draw` (draft, re-paper to US Letter, render,
measure), look at the render, repair with `akcli` (dry-run every op-list, read
the net diff), re-render, iterate on the measurable costs. The `RECORD.md`
carries the verification set from the skill before and after repair.

### 5. Handing it back

The render goes to the owner **first**, with a request for evaluation and
nothing else (`EVALUATING-DRAWINGS.md` §4). If he asks, it can be placed beside
the existing sheet, unranked. Measurements follow only on request.

**Whether a copperhead page replaces the current sheet is the owner's call**,
made after seeing it. Until then `perfboard.json`, the round-trip tests and the
build guide keep pointing at the existing sheet.

## What this is not

- Not a change to the existing staged sheet.
- Not a general "derive any board's intent" feature. The module is written for
  boards whose components carry `symbol` and a designator map, and refuses
  others by name. The Pultec intents stay as they are.
- Not a verdict on any drawing. Approval is recorded by the owner only.
